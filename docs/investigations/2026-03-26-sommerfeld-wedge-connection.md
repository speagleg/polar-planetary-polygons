## Observation

at quarter-integer arguments: Gamma(5/4), Gamma(9/4), with prefactor
pi^{-(1/4 + it/2)}.

These match Kobayashi's (1991) generalized Gamma kernels for
electromagnetic diffraction from a wedge of exterior angle 3pi/4.

## Key formulas

- Kobayashi kernel: K(s) = Gamma(s/nu) * pi^{-s/nu}
- For nu = 4: K evaluates at s = 1,5,9 to Gamma(1/4), Gamma(5/4), Gamma(9/4)
- Wedge half-angle = pi/4, exterior = 3pi/2, complement = 3pi/4
